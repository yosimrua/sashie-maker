# 02_画面UI設計

本アプリケーションは、Localhost環境での利用を想定したシングル画面のデスクトップ向けダッシュボードUIで構成します。「キャラクター管理」と「シーン・挿絵生成」の2つの主要機能をタブで切り替えて使用でき、小説管理はヘッダーからグローバルにアクセス・選択できます。

---

## 1. 画面構成一覧

### 1.1 メインナビゲーション（ヘッダー）
- **アプリタイトル**: 左端に「🎨 挿絵メーカー」を表示。
- **小説切り替えプルダウン**: タイトルのすぐ右隣に配置。データベースに保存されている小説プロジェクト（例：「AI事務員宮西さん」等）をプルダウンで瞬時に切り替え可能。
- **「＋ 新規小説を作成」ボタン**: プルダウンのさらに右隣に配置。クリックすると小説管理画面（設定・一覧・削除）へ遷移し、入力フォームがクリアされ新規作成モードになります。
- **機能タブメニュー**: 右側に「👤 キャラクター管理」「🎬 シーン・挿絵生成」のタブ切り替えボタンを配置。

### 1.2 小説管理画面（独立設定画面）
※「＋ 新規小説を作成」ボタンをクリックするか、小説編集を行う際に表示される画面です。
- **小説の設定・編集（左側）**:
  - 小説タイトル、あらすじ・概要メモのテキストエリア。
  - **「小説プロジェクトを保存」ボタン**: 小説情報を新規登録または更新保存します。
- **小説プロジェクト一覧（右側）**:
  - 登録済みの小説一覧をカード型で表示。カードを選択するとその小説の編集モードになり、キャラクターやシーンの読み込みもその小説のものに切り替わります。「削除」ボタンによる関連データの一括削除も可能です。

### 1.3 キャラクター管理画面
- **新規登録フォーム（左側）**:
  - キャラクターの名前入力、立ち絵画像（PNG/JPG/WebP）の選択・ドロップエリア。
  - **「1. AI設定読み込み (外見解析)」ボタン**: 画像入力後にこのボタンを押すと、AIが立ち絵画像を解析し、中央のエディタに初期設定Markdownを生成・反映します。
  - **「立ち絵をPCへダウンロード」ボタン**: 現在選択している立ち絵画像をPNG形式でローカルPCへダウンロードします。
  - **「2. キャラクターを保存」ボタン**: 編集内容をデータベースへ保存します。その際、まだ生成されていない「正面」「横向き」の別ポーズ立ち絵画像が自動的に並列で同時生成・透過処理され、一括保存されます。
- **キャラクター設定エディタ（中央）**:
  - 外見特徴(Visual)と詳細プロフィール(Profile)の2つのMarkdownテキストエリア。
  - **ポーズ画像ライブラリ**: 保存後に自動生成された「正面」「横向き」および元の「インプット画像」を表示切り替えするエリア。
- **キャラライブラリ（右側）**:
  - 登録されているキャラクターの立ち絵サムネイル一覧。選択することで編集可能です。

### 1.4 シーン・挿絵生成画面
- **シーン設定・入力（左側）**:
  - シーン名入力、小説本文（テキスト）入力エリア。登場キャラクターのチェックボックス選択、アスペクト比（2:3 / 3:4）の指定。
  - **「1. 本文からシーン設定をAI抽出」ボタン**: シーン設定Markdownを自動抽出して中央エディタに反映。
  - **過去のシーンライブラリ**: 作成済みのシーン一覧を表示。選択して切り替えや削除が可能。
- **シーン設定エディタ（中央）**:
  - AI抽出された構図や背景等の指示Markdownをユーザーが微調整するテキストエリア。
  - **「2. 挿絵を生成 (4構図並列)」ボタン**: 4種類の構図画像を並列同時生成します。
- **プレビュー & ライブラリ（右側）**:
  - メインプレビュー画面。
  - **同時生成の4構図グリッド**: 生成された4つの構図（三分割、日の丸、三角形、対角線）を比較選択する2x2サムネイル。
  - **「3. PCへダウンロード」ボタン**: 表示中の画像をローカルへ保存.
  - **確定保存済みの履歴リスト**: シーンに紐づいて保存されている画像履歴の一覧。

## 3. デザイン方針
- **カラーテーマ**: ダークテーマ（背景：深めのグレー `#121214` / `#1a1a1e`、アクセントカラー：ライトイエロー `#ffd200`）を基調とし、暗い部屋での執筆作業時でも目が疲れにくい配色を採用。
- **レイアウト構造**: 画面左右にスクロールバーが独立して現れる構成にし、入力側が長くなってもプレビュー枠や操作ボタンが常に画面内に固定表示されるように設計。
- **操作フィードバック**: 画像生成の進行状況（プログレスバー等）と、過去履歴の切り替え時のシームレスなローディング表示の実装。
