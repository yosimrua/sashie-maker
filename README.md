# 挿絵メーカー (Sashie Maker)

ライトノベルの挿絵を簡単に作成・編集できるアプリケーションの開発プロジェクトです。

---

## 📁 ディレクトリ構成・工程ガイド

個人開発において、ウォーターフォール風の工程に沿ってスムーズに開発・ドキュメント管理を行えるよう以下のフォルダ構造で整理しています。

```text
挿絵メーカー/
├── README.md                     # 本ファイル（全体概要・各工程へのインデックス）
├── 01_企画・要件定義/             # Phase 1: 企画・コンセプト・機能要件の定義
│   ├── 01_企画書.md
│   └── 02_要件定義書.md
├── 02_設計/                      # Phase 2: アーキテクチャ・UI/UX設計
│   ├── 01_基本設計.md
│   └── 02_画面UI設計.md
├── 03_開発/                      # Phase 3: ソースコード・実装
│   ├── README.md
│   └── src/ (予定)
└── 04_公開/                      # Phase 4: ビルド・デプロイ・リリース管理
    ├── 01_ビルド・デプロイ手順.md
    └── 02_リリースノート.md
```

---

## 🚀 各工程の進め方

1. **[01_企画・要件定義](./01_企画・要件定義/)**
   - アプリで解決したい課題、作りたい機能の洗い出し、要件定義を行います。
2. **[02_設計](./02_設計/)**
   - 技術スタック選定、データ構造、UI画面レイアウトやプロンプト生成ロジックの設計を行います。
3. **[03_開発](./03_開発/)**
   - 実際にソースコードを記述し、動作検証を行います。
4. **[04_公開](./04_公開/)**
   - ビルド、デプロイ、配布およびリリース情報の管理を行います。
