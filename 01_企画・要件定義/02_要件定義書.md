# 02_要件定義書

## 1. 概要・システム範囲

本システムは、ユーザーが登録した**「キャラクターの立ち絵画像」**と**「小説のシーン文章」**を取り込み、キャラクターのビジュアル（顔・服装・特徴）を維持したまま、小説の該当シーンに合わせたライトノベル風挿絵画像を生成・管理・プレビューするアプリケーションです。

---

## 2. ユーザーフロー

1. **キャラクター登録**: 立ち絵画像（PNG/JPG）をアップロードし、名前を入力すると、AIが自動でキャラクター特徴プロパティ（プロンプト等）を解析・設定する。
2. **シーン作成**: 挿絵にしたい小説本文（シーン文章）を入力し、登場キャラクターを選択すると、AIが本文からシチュエーション（構図・表情・背景など）を自動生成する。
3. **挿絵生成**: 設定された条件を元に、NanobananaPro APIを通じて画像生成を実行する。
4. **確認・保存**: 生成された画像をシンプルプレビューで確認し、NanobananaPro標準機能で画像として保存・ダウンロードする。



---

## 3. 機能要件

### 3.1 小説プロジェクト管理機能 (Novel Management)
- [ ] **小説（プロジェクト）の作成・選択・削除**
  - 複数の小説（例: 「AI事務員宮西さん」等）をデータベースに個別に登録・管理する機能
  - ヘッダー部分のプルダウンメニューから編集したい小説プロジェクトを切り替えて選択できる仕様
  - 選択された小説に属するキャラクターやシーン情報のみが連動して表示・編集・保存される仕様
- [ ] **ヘッダーからの小説管理・作成アクセス**
  - プルダウンの右隣に「＋ 新規小説を作成」ボタンを配置し、クリックすると新規入力モードにクリアされた状態で小説管理画面（設定・あらすじ編集・一覧・削除）へ遷移する仕様
- [ ] **あらすじ・概要・メモ記述**
  - 小説の概要、あらすじ、プロット、執筆用メモを自由に記述・保存できるテキストエリア機能

### 3.2 キャラクター管理機能 (Character Management)
- [ ] **立ち絵画像の登録・保持**
  - キャラクターの参照用立ち絵イラスト（PNG / JPG / WebP）のアップロード機能
- [ ] **キャラクター外見特徴MarkdownのAI自動生成 (Visual)**
  - アップロードされた立ち絵画像を解析し、AIが外見特徴のみをまとめた設定Markdownテキストを自動生成する機能
  - **定義するMarkdown構造 (完全固定 - characterVisualフィールドに保存)**:
    ```markdown
    # [キャラクター名] - 外見特徴
    ## 1. 基本ビジュアル
    - 性別: 
    ## 2. 詳細ビジュアル
    - 髪型・髪色: 
    - 瞳の色: 
    - 服装: 
    - その他特徴: 
    ```
- [ ] **キャラクタープロフィール・設定Markdownの編集機能 (Profile)**
  - ユーザーが手動で記述・編集する、キャラクターの生い立ちや性格等をまとめたMarkdownテキストを保存できる機能
  - **定義するMarkdown構造 (完全固定 - characterProfileフィールドに保存)**:
    ```markdown
    # [キャラクター名] - 詳細設定
    ## 1. プロフィール
    - 年齢 / 外見年齢: 
    - 職業 / 役割: 
    ## 2. キャラクター性
    - 性格: 
    - 武器・能力: 
    - その他補足: 
    ```
- [ ] **設定Markdownの自由編集機能**
  - AIが生成した外見特徴(Visual)と、ユーザーが記述するプロフィール(Profile)の双方（それぞれ最大2万文字）を、ユーザーが自由に追加・編集して保存できる機能


- [ ] **立ち絵バリエーション（別ポーズ）の自動同時生成・登録機能**
  - キャラクターの保存をトリガーとして、インプット元画像からキャラクターの服装や表情の一貫性を維持したまま、以下の別ポーズ画像を裏側で自動的・並列にAI（NanobananaPro）により同時生成して一括保存する機能
    - 正面（Front view pose）
    - 横向き（Side view pose）


- [ ] **簡易キャラクターライブラリ管理**
  - 登録されたキャラクターの名前と立ち絵画像のみを表示するシンプルな管理一覧
  - キャラクターの追加、名前・設定Markdownの編集、および削除機能



### 3.2 シーン管理機能 (Scene Management)
- [ ] **シーン文章の登録・管理**
  - 挿絵対象となる小説本文（段落・エピソードテキスト）の入力および一覧保存
- [ ] **登場キャラクターの紐付け**
  - キャラクターライブラリから、シーンに登場するキャラを選択
- [ ] **AIによるシーン設定Markdownの自動生成**
  - 入力されたシーン文章（小説本文）をAIが解析し、挿絵に必要なシチュエーションをまとめたシーン設定Markdownテキストを自動で生成する機能
  - **定義するMarkdown構造 (完全固定)**:
    ```markdown
    # シーン設定概要
    ## 1. 登場人物と状態
    - 登場キャラクター: 
    - 各キャラの表情: 
    - 各キャラのポーズ・アクション: 
    ## 2. 構図・カメラワーク
    - カメラアングル: 
    - キャラクターの配置: 
    - 視線の方向: 
    ## 3. 背景・環境
    - 場所・環境: 
    - 時間帯・天候: 
    - 光源・ライティング: 
    - 全体の雰囲気: 
    ```
- [ ] **シーン設定Markdownの自由編集機能**
  - AIが生成したシーン設定Markdown（最大2万文字）を、ユーザーが自由に追加・変更・微調整して保存できる機能




### 3.3 挿絵生成 & プロンプト自動生成機能
- [ ] **複数アングル画像の参照による同一性強化**
  - 登録された立ち絵画像（インプット画像、正面、横向き）が存在する場合、これら全ての画像をAIへ同時に参照入力し、キャラクターのビジュアル同一性を維持する機能
- [ ] **白背景自動透過システム**
  - アップロードされた画像および生成された正面・横向き立ち絵画像から、HTML Canvas を用いて白色の背景領域を自動で検出し、透過PNGに加工して保持する機能
- [ ] **作業ステータスの永続化と復元**
  - ブラウザのリロード時やPCの再起動時にも、最後に開いていたタブ、選択されていたキャラクター、シーンなどの作業状態を localStorage により維持・復元する機能
- [ ] **NanobananaPro API連携**
  - NanobananaPro画像生成APIとの通信・生成実行


- [ ] **アスペクト比・画質パラメータ設定**
  - ラノベ挿絵用縦長アスペクト比（2:3, 3:4 等）および解像度指定
- [ ] **4構図同時並列生成・自動保存機能**
  - 1回の実行で異なる4つのカメラ構図（①三分割構図、②日の丸構図、③三角形構図、④対角線構図）の画像を並列生成し、2×2グリッドで比較表示する機能
  - 生成された4つの構図画像は、シーンの生成履歴に自動的に一挙保存される仕様とする。


### 3.4 プレビュー & 出力機能
- [ ] **シンプル画像プレビュー**
  - 生成された挿絵画像を画面上に表示するだけのシンプルなビューワー
- [ ] **生成挿絵の独立保存（履歴管理）**
  - 生成された画像をシーンに紐づく独立した画像データとしてアプリ上のローカルストレージ（IndexedDBの別テーブル）に複数枚保存・蓄積できる機能
- [ ] **クライアントマシンへのダウンロード**
  - 保存された画像履歴から、指定した画像をローカルマシンにダウンロード（PNG/JPEG等で保存）できる機能



---

## 4. 非機能要件

- **動作環境・システム構成**: Localhost（ローカルPC）上でサーバーを起動して利用するWebベースのアプリケーション。外部への公開は想定しない。
- **UI/UX・操作性**: 立ち絵と本文をセットするだけで、残りの複雑なプロパティ調整やシチュエーション設定はAIが代行する、手間の少ない直感的UI
- **データ保持・プライバシー**: 登録した立ち絵画像、キャラ設定、シーン文章、生成履歴はブラウザ/ローカルストレージ（IndexedDB等）に安全に保存
- **拡張性**: 今後画像生成APIの仕様変更に対応しやすいモジュール構造
